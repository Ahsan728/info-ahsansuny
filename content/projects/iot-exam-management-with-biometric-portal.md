## Abstract

Using Internet of Things (IoT) in present examination system can make whole process more reliable, effective & accurate. Nowadays online examination has made education system more efficient because it reduces both cost & time. But in Bangladesh we still use conventional system in examination which is not reliable. Running system is time consuming & inefficient. With IoT & Fingerprint module we have designed such a system which can easily detect the examinee & provide exam script in an automated way before starting examination. Cloud computing is used to store information that will go through fingerprint module. All data are stored in cloud with respect to fingerprint of each examinee. Further, the automation part runs only if the fingerprint of an examinee is matched with previously stored fingerprint. Exam controlling authority can observe every student’s entry & real time information through website.
